# Catalog V1 fixtures

Owner: test maintainers.

This directory contains reproducible synthetic positive and negative Catalog V1 fixtures. Fixtures must be clearly test-only, contain no production authorization material, and remain safe to publish.

`candidate/valid` is regenerated from the checked sources with
`SOURCE_DATE_EPOCH=1785312000`; focused tests compare every path, mode, and byte.
`candidate/invalid` contains strict-parser negatives, with semantic and
filesystem negatives generated by the focused package tests.
